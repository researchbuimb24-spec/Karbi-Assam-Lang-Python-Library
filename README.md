# Karbi Language Python Library (`karbi`)

A comprehensive, open-source Python library and cultural knowledge repository for the **Karbi language** (*Arleng alam*), primarily spoken in the Karbi Anglong and West Karbi Anglong regions of Assam, India *(demographic and geographic descriptions subject to formal verification against census and scholarly sources)*.

> [!IMPORTANT]
> **Verification & Provenance Notice:** All linguistic classifications, orthographic standards, dialect designations, and cultural narratives in this project are preliminary working outlines that require formal verification against authorized academic publications, recognized community bodies, or native speaker authorities. Unverified claims, synthetic data, or AI-generated candidates will not be treated as established facts.

---

## Mission & Long-Term Objectives

* **100,000+ Verified Entries:** Build a rich, scalable linguistic repository including dictionary headwords, parts of speech, phonetics, and usage notes.
* **Multilingual Translation:** Provide lookup and reverse translation between Karbi and major languages including English, Hindi, and Marathi.
* **Linguistic Depth:** Document Karbi alphabets, orthography (such as the Roman script conventions published by *Karbi Lammet Amei*), pronunciation, numerical counting classifiers, and grammar. *(All orthographic standards and dialectal variations require formal citation and academic/community review).*
* **Cultural Knowledge:** Document traditional rituals, folklore, oral narratives, songs, and indigenous knowledge systems with strict adherence to cultural permissions, intellectual property ethics, and primary source provenance. *(All cultural entries require community consent and verifiable sourcing).*
* **Strict Verification Pipeline:** Transparently distinguish authentic, elder/scholar-verified records from automated or AI-assisted candidate entries.

---

## Architecture Overview

To accommodate over 100,000 entries efficiently without crashing editors or causing high memory usage, this project utilizes a two-tier architecture:

1. **Source Data Tier (`data/`):** Human-readable, sharded JSON Lines (`.jsonl`) files tracked in Git. This allows contributors to easily review additions and maintain clean version history.
2. **Runtime Engine Tier (`karbi.db`):** An embedded SQLite database with Full-Text Search (FTS5) built automatically from source data, with zero external server dependencies. (Performance goal: sub-millisecond query execution, to be established and validated through systematic benchmarking).

---

## Verification & Provenance Levels

Every entry in this library carries an explicit verification status:

* `VERIFIED`: Confirmed by published scholarly dictionaries, academic institutions (e.g., Karbi Lammet Amei, Universities), or community elders.
* `COMMUNITY_SUBMITTED`: Contributed by native speakers or language learners, pending review.
* `AI_CANDIDATE`: Generated by AI models or automated scrapers. **Never treated as established fact until reviewed.**
